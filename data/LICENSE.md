# License of the processed data

The file `obb_certified_data.zip` contains records derived from the iSAID annotations
(Zamir et al., 2019) and from the DOTA v1.0 images and labels (Xia et al., 2018): reference hulls,
matches, mask outlines, detections, scores, intermediate outputs and logs.
